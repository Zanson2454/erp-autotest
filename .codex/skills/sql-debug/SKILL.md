# SQL Debug Skill

## 适用场景
当用户提出以下任务时，优先使用本技能：
- 排查慢 SQL
- 分析查询结果异常
- 核对数据不一致
- 优化索引
- 处理 join、group by、事务、锁等待问题

## 输入信息要求
尽量收集以下信息：
- SQL 语句
- 表结构
- 索引信息
- 数据量级
- 执行计划
- 现象描述
- 期望结果
- 实际结果
- 数据库类型及版本
- 事务隔离级别
- 慢日志 / 锁等待信息

## 执行步骤
1. 明确问题类型
   - 查询慢
   - 结果错误
   - 数据重复
   - 数据缺失
   - 死锁 / 锁等待
   - 更新影响行数异常

2. 核对 SQL 逻辑
   - where 条件是否正确
   - join 条件是否遗漏
   - 聚合逻辑是否合理
   - 排序/分页是否稳定
   - null 值处理是否正确

3. 查看执行计划
   - 是否走索引
   - 是否全表扫描
   - 是否回表严重
   - 是否临时表/文件排序
   - 连接顺序是否异常

4. 校验数据特征
   - 数据量
   - 数据分布
   - 倾斜情况
   - 脏数据
   - 重复数据

5. 给出优化方案
   - 改写 SQL
   - 补索引 / 调整索引
   - 拆分查询
   - 预聚合 / 缓存
   - 调整事务范围
   - 限制查询范围

## 注意事项
- 不要只说“加索引”，要说明索引为什么有效
- 优化前先确认结果正确性，不能只追求快
- 分页查询要关注排序字段是否稳定
- ERP 场景重点关注：
  - 单据主子表 join
  - 库存台账汇总
  - 金额聚合
  - 多组织隔离条件
  - 状态字段过滤遗漏
