# Debugging Triage Skill

## 定位

本 skill 负责先定位方向，不直接承担完整修复。需要改代码时转交 `bugfix`，SQL 问题转交 `sql-debug`。自动触发由 `workflow-trigger` 统一处理。

## 适用场景

- 问题现象不清晰，需要先分层定位
- 无法稳定复现，需要构造最小复现路径
- 需要判断应该走应用修复还是 SQL 专项排查

## 执行步骤

1. 明确现象与影响范围（用户、模块、数据）。
2. 建立最小复现路径（入口、前置数据、触发动作、异常结果）。
3. 分层排查（日志、调用链、接口、数据库、异步任务）。
4. 给出分诊结论与下一步动作。

### 3. 分诊结论
- 建议后续 skill：
- 原因：

## 注意事项
- 证据不足时明确推测与待验证项。
- 不在分诊阶段直接做大改动。
