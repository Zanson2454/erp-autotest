# Brainstorming Skill

## 定位

本 skill 是设计类任务的执行技能，不负责自动触发。自动触发由 `workflow-trigger` 统一处理。

## 适用场景

- 需求不清晰，需要先澄清边界
- 同一需求存在多种实现路径，需要做方案对比
- 需要输出可落地的实施步骤和风险控制

## 执行步骤

1. 澄清目标与约束（业务目标、时限、资源、兼容性）。
2. 输出 2-3 个可行方案并比较成本、风险、收益。
3. 给出推荐方案与不选其他方案的理由。
4. 产出最小可落地步骤（里程碑、依赖、验收标准）。

|---|---|---|---|

### 3. 推荐方案
- 推荐理由：
- 关键取舍：

### 4. 落地计划
- 里程碑：
- 依赖项：

## 注意事项
- 先做边界澄清，再做技术细节。
- 不在此 skill 内直接进入大规模代码改动。
