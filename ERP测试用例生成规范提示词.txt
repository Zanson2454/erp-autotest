### 📋 使用说明
- 配合 @testcase_temp.mdc 使用，本文件为快速参考版本
- 适用场景：基于curl命令快速生成标准测试用例

### ⚡ 核心流程
1. **API匹配**：提取curl中serviceKey → 在对应模块api_path.yaml查找key
2. **参数过滤**：ParamUtil.filter_post_body_fields() 过滤业务字段
3. **标准结构**：遵循项目既定模板，不自行优化架构

### 🔥 快速模板
```python
@case_decorator(order=1, severity="critical", tags=["模块"])
def test_功能操作(self):
    """功能说明"""
    try:
        # 1. API调用
        api_path = self.get_api_path("匹配的key")
        params, url = self.get_api_params(api_path)
        
        # 2. 参数处理  
        filtered_params = ParamUtil.filter_post_body_fields(
            params, ["业务字段列表"], ["params", "request"]
        )
        set_dict = {"字段": "值"}
        ParamUtil.set_request_params(filtered_params, set_dict)
        
        # 3. 请求与断言
        response = self.http.post(url, json=filtered_params)
        self.assert_util.assert_response_data(response)
        
        # 4. 报告记录
        a.json(filtered_params, "请求数据")
        a.json(response, "响应数据")
        
    except Exception as e:
        a.text(str(e), "失败原因")
        raise
```

### 🎯 关键要点
- **严格复用**：使用项目既定工具类和方法
- **参数过滤**：必须使用ParamUtil.filter_post_body_fields，只过滤业务字段
- **异常处理**：所有用例必须包含try-catch结构
- **字段过滤规范**：
  - ❌ 禁止过滤：sceneKey, viewKey, appId, teamId, serviceKey
  - ✅ 只过滤业务字段：如pageable, fields, request等实际业务参数
