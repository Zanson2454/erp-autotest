# API Test Skill

## 适用场景
当用户提出以下任务时，优先使用本技能：
- 设计接口测试用例
- 分析接口风险
- 编写接口测试脚本
- 校验接口返回是否合理
- 排查接口联调问题

## 输入信息要求
尽量具备以下信息：
- 接口路径
- 请求方法
- 请求头
- 入参说明
- 响应结构
- 鉴权方式
- 业务规则
- 错误码定义
- 幂等要求
- 示例请求/响应

## 执行步骤
1. 明确接口职责
   - 是查询、创建、更新、删除还是状态流转
   - 是否影响核心业务数据

2. 拆解测试维度
   - 正常请求
   - 必填校验
   - 类型校验
   - 长度校验
   - 枚举值校验
   - 权限校验
   - 重复提交 / 幂等校验
   - 状态前置校验
   - 数据隔离校验
   - 异常码校验
   - 响应字段完整性校验

3. 设计测试数据
   - 合法数据
   - 非法数据
   - 边界数据
   - 跨角色数据
   - 脏数据 / 历史数据

4. 输出测试建议
   - 测试点
   - 脚本结构
   - 断言建议
   - 风险提示

## 注意事项
- 接口测试不能只看返回码，要核对数据库和业务结果
- 查询接口要关注分页、排序、筛选条件组合
- 写接口要重点关注幂等、事务、状态流转和权限
- ERP 场景重点校验跨组织、跨仓库、跨角色的数据隔离
