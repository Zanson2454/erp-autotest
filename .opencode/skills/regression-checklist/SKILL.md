# Regression Checklist Skill

## 适用场景
当用户提出以下任务时，优先使用本技能：
- 输出回归测试清单
- 评估改动影响面
- 发布前确认检查项
- 缺陷修复后补充回归范围
- ERP 版本迭代回归梳理

## 输入信息要求
尽量具备以下信息：
- 本次变更内容
- 涉及模块
- 修改文件
- 涉及接口
- 涉及表
- 关联上下游
- 历史高频问题
- 发布范围
- 风险等级

## 执行步骤
1. 识别改动类型
   - 新增功能
   - 缺陷修复
   - 重构
   - 配置变更
   - SQL / 数据修复
   - 第三方集成变更

2. 分析影响面
   - 直接影响模块
   - 间接影响模块
   - 同类功能
   - 公共组件
   - 公共接口
   - 公共数据模型

3. 输出回归清单
   - 核心主流程
   - 上下游联动
   - 角色权限
   - 异常流程
   - 历史易错点
   - 数据正确性
   - 性能/安全冒烟

4. 标记优先级
   - P0：必须回归
   - P1：建议回归
   - P2：有时间再回归

## 注意事项
- 回归清单必须结合实际改动，不要写成通用废话
- 修一个点，至少检查同类场景和逆向流程
- ERP 场景发布前重点检查：
  - 创建/提交/审核/反审核/作废
  - 库存增减
  - 金额计算
  - 单据关联
  - 数据权限
  - 定时任务
  - 报表统计
