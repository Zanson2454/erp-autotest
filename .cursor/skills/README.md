# Cursor Skills Index

## Available
- `workflow-trigger`: unified routing entry for project workflows and domain skills.
- `curl-to-testcase`: convert recorded curl flows to pytest cases.
- `erp-full-flow`: run full framework analysis and output docs.
- `brainstorming`: requirement clarification and option comparison.
- `systematic-debugging`: structured triage and root-cause path.
- `semantic-context-construction`: build reproducible context packages.
- `contract-constraint-design`: define executable assertion contracts.
- `agentic-protocol-orchestration`: design role/state/tool protocols.
- `failure-knowledge-flywheel`: turn failures into reusable priors.
- `digital-anti-entropy`: govern drift and automation entropy.
- `harness-workflow-trigger`: Harness topic routing alias.

## Usage
Use manual trigger in chat:

```text
@workflow workflow-trigger
```

Then select a request template from `/.cursor/workflows/request_templates.md` and paste it into chat.

Then provide one clear goal, for example:
- "把 recorded_flow_001 转成 gen_md 用例"
- "做一次 ERP 自动化框架全流程分析"
